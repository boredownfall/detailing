Как обновлять фото кейсов

1. Загрузите фото в GitHub в папку assets/cases/
2. Для уже подготовленных карточек используйте имена:
   bmw-x5.webp
   zeekr-001.webp
   li-auto-l7.webp
   mercedes-gle.webp
   voyah-free.webp

Рекомендуется WebP, ширина 1400–1800 px, ориентир 200–500 КБ на фото.

Если используете .jpg/.png или другое имя файла — поменяйте src у нужной картинки в секции id="works" в index.html.

Чтобы добавить новый кейс:
скопируйте один <article class="work-card">...</article> и поменяйте src, alt, модель, тип работ и срок.
