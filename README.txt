BRONYA AUTO — WEB ASSETS

Содержимое:
- assets/cases/full/ — полноразмерные WebP для hero, кейсов и SEO-страниц
- assets/cases/thumbs/ — облегчённые превью для карточек/галереи
- assets-manifest.json — соответствие исходников и новых имён

Вторая пачка: 12 полезных кадров. Фото 37 не включено: дублирует BMW-кадр и имеет грубую белую маску на номере.

Рекомендация по загрузке:
1) Скопировать папку assets в корень проекта.
2) На главной использовать loading="eager" только для hero, остальные loading="lazy".
3) Для карточек использовать thumbs, для кейсов/hero — full.
4) width/height указывать в HTML, чтобы избежать layout shift.
